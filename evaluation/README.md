# Evaluasi & Komparasi Model (Fase 3)

**Penanggung Jawab:** Gisca (Anggota 3)

Folder ini digunakan untuk rekapitulasi evaluasi komparatif dari kelima model yang dilatih oleh seluruh anggota tim.

## Tugas Evaluasi
1. Mengumpulkan metrik pengujian dari seluruh notebook di folder `notebooks/`.
2. Membuat tabel perbandingan gabungan (*Leaderboard*):
   - Model
   - Accuracy
   - Precision
   - Recall (Dropout)
   - F1-Score
   - ROC-AUC
   - Waktu Latih (detik)
3. Membuat visualisasi gabungan:
   - Grafik batang perbandingan performa.
   - Plot kurva ROC-AUC gabungan (5 model dalam 1 grafik).
   - Plot Confusion Matrix untuk masing-masing algoritma.
4. Menentukan **Best Model** untuk ditanam ke dashboard Streamlit.
